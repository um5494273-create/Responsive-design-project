# 🍎 Apple Website Clone

A responsive Apple-inspired website created using **HTML and CSS only**.  
This project is designed to recreate the clean and minimal look of Apple's product website.

## 🌐 Live Demo

🔗 [View Live Website](https://um5494273-create.github.io/Responsive-design-project/)

## 🚀 Features

- Clean and modern Apple-inspired UI
- iPhone product hero section
- Navigation bar with Apple-style menu
- Product cards for:
  - iPhone
  - MacBook Air
  - Apple Watch
  - AirPods
- Learn More and Buy links
- Responsive design for **mobile phones**
- Simple and lightweight layout

## 🛠️ Technologies Used

- **HTML5**
- **CSS3**

> No JavaScript or external frameworks were used.

## 📱 Responsive Design

The website is specifically made responsive for **mobile phone screens** using CSS media queries.
